# 破甲模式

破甲模式将用户提供的正文放在系统提示词首部，保留 DSH 原有身份、工具说明和约束。组件没有预置破甲词。独立新会话始终关闭，必须由用户在该会话中显式选词并通过模型白名单校验后才能开启。通过 DSH 原生组件开关启停，停用清理运行资源并保留文件。

## 文件位置

| 数据             | 路径                                          |
| ---------------- | --------------------------------------------- |
| 用户破甲词       | `$DSH_HOME/system_inject/prompts/*.md`        |
| 用户模型白名单   | `$DSH_HOME/system_inject/config.json`         |
| 工程破甲词       | `<工作区>/.dsh/system_inject/prompts/*.md`    |
| 会话冻结状态     | 原生会话目录内的 `system_inject.json`         |
| 首次请求资格标记 | 原生会话目录内的 `system_inject.pending.json` |

DSH_HOME 通常为 `~/.dsh`。用户文件在同一 DSH_HOME 的 Desktop/Web profile 之间共享。工程目录严格取会话工作区，不寻找父目录；只扫描 prompts 直属 `.md`，不扫描子目录。文件是唯一数据源，可以通过设置页或外部编辑器维护。

会话目录根据活动原生 JSONL 后端的实际 root 和原生目录编码定位，支持自定义存储根目录。Cordis 4.1 从 `effectiveConfig` 读取已求值的 root，Cordis 4.0 从 `config` 读取。无法识别或存在多个活动后端时拒绝写入。备份、移动会话时必须包含整个目录及伴随文件。

## 破甲词格式

```markdown
---
name: example
display_name: 示例名称
description: 可选简介
---

这里是正文。
```

name 是必填索引，大小写敏感，最多 120 字符，仅允许字母、数字、点、连字符、下划线，不能为 `.` 或 `..`。设置页新建文件使用 `name.md` 并检查跨平台文件名合法性。文件名不参与索引；移动或改文件名不改变引用。

display_name 省略时使用 name；description 可选。正文按字面注入，不展开变量，换行统一为 LF。OMP 的 status 等额外字段不参与执行；编辑保存时只写受支持的元信息。用户、工程同名或同层重名均显示冲突，不能用于新请求；损坏文件明确显示路径和错误，不会伪装为空库。

## 显式选择与统一状态

用户配置示例：

```json
{
  "version": 1,
  "whitelist": [{ "provider": "provider-id", "model": "model-id" }]
}
```

用户 config.json 只接受 version 和 whitelist，未知字段明确报错。工程只提供破甲词库，不能通过工程配置授权模型。

会话使用 InjectState：`{"name": null}` 关闭，`{"name": "example"}` 引用用户显式选择的破甲词。选择接口要求明确的 name，不接受空状态 `{}`。打开界面、创建模板、授权模型、切换工作区或模型，都不会自动开启破甲。

未发送的会话选择仅保留在宿主内存；同一宿主窗口共享，浏览器刷新保留，宿主或组件重载后回到关闭，需重新显式选择。UI 使用宿主统一解析结果：有效选择显示橘红裂盾、显示名称和静态红色外扩光晕；关闭显示灰色完整盾牌及“未破甲”；名称缺失或冲突显示“已失效”。选词及选模在保存前由宿主校验组合；不兼容时在当前入口提示（本包和原生模型按钮使用官方 Toast，原生 `/model` 保留内联拒绝），并保留原来已确认的组合。拒绝后切换兼容模型不会自动开启，仍需主动选词。

展示、选模和请求护栏读取同一会话解析结果，优先使用冻结快照，其次使用本次请求已捕获的候选，最后解析本会话显式选择。结果为关闭时不执行模型授权校验，也不因模板目录或白名单读取错误阻止正常请求；文件诊断仍在管理页和选择菜单显示。用户主动开启破甲被拒绝时仍会提示，但该通知只代表这次操作；Toast 自动结束后按通知 ID 确认并清理，不因切换会话、返回空白草稿而重复弹出。确认通信失败会在后续刷新时重试，不改变已确认的破甲状态，也不清除后来的新通知。

只有新会话可以选择破甲词，宿主的 `resolved.editable` 是唯一判据。已有请求历史且无快照或资格标记的会话会补写明确关闭快照，保持只读，不允许补选。已有会话点击入口直接查看只读模态窗，可查看名称、来源、正文并复制，不提供更换或关闭。

## 冻结与请求护栏

首次请求装配前在原生会话目录原子写入 `system_inject.pending.json`，内容仅为 `{"version":1}`，证明尚未放行首次请求，不保存选词或正文。随后捕获不可变候选状态，按实际分发的 provider 和 model 精确匹配白名单，并核对请求首段。开启时相关文件变化会取消本次请求，需重新发送；关闭候选不依赖这些文件。全部校验通过后才持久化会话快照，再交给适配器；关闭状态也会冻结。校验或写盘失败不调用适配器，通过官方 Toast 提示；API 调用失败仍保留快照。冻结成功后清理资格标记；准备或护栏失败保留标记，重启后仍允许选择，但内存选择丢弃并恢复关闭。即使标记清理失败，冻结文件始终优先。

冻结文件包含版本、state、frozen_at、source，以及可选 inherited_from。source 只允许 session（本会话选择）、parent（继承父会话）和 none（未开启）。开启时 state 附带 snapshot（display_name、description、body）；关闭时 name 为 null，不附带正文。后续展示与请求优先读取本会话副本，不扫描模板、不锁定这些目录；仅在选模与实际请求时读取最新用户白名单。快照读取失败时该会话明确报错且只读，不回退为新会话，也不影响其他会话的加载。编辑、删除和改名不会改变已冻结正文。

本地 fork、spawn、团队成员及其后代继承相同冻结结果（包括关闭状态），首次继承即各自持久化独立副本；之后恢复不依赖父会话存在。首次继承无法确认父状态时明确失败。

选模前置校验覆盖本包选择器、原生选择器和 `/model`；选词、选模、首次捕获使用同一宿主队列，拒绝不写原生模型记录，不采用回滚。白名单还在实际请求阶段校验，覆盖重试、继承状态的本地 fork/spawn/团队成员和携带正文的辅助请求。撤销授权影响后续请求，不剥离正文后继续发送。DSH 在运行中切换模型时可能在下一工具步骤采用新模型，该请求仍受护栏约束。独立 ACP/Codex/Claude 运行时不接管。

完整系统预设等配置可能压掉首段；实际请求不含预期正文时明确拒绝，不静默忽略。其他插件、原生提示词或服务商变化仍可能影响缓存。停用本组件或总包会撤销注入、选模校验和请求护栏，系统提示词随后按 DSH 原生规则变化。

## 编辑与维护

设置页仅包含模板库和模型白名单两个分区，分类图标为中性裂盾。全局设置只管理用户破甲词库；从输入框进入时同时管理全局与当前会话项目的破甲词。范围由入口固定，不提供工程切换器，两个入口不共享可变范围状态。新建/导入默认保存到全局用户目录；只有项目入口可以选择保存到当前项目，编辑已有文件不改变来源。白名单始终为全局用户配置。名称、显示名称、简介和正文显式保存。

模板库顶部搜索名称、短标识和简介，下方按“全局”“工程”分为独立可折叠的组；全局设置只显示全局组。破甲词卡片呈现显示名称、简介、短标识及名称冲突提示，点击卡片进入编辑，右上角菜单提供编辑、导出和删除。搜索时自动展开分组，仍可手动折叠；编辑返回保留搜索和折叠状态。

模型白名单以矮卡片展示模型与提供商，顶部可搜索已授权条目，右侧红色垃圾桶删除授权。新增菜单按提供商分组，支持搜索、方向键与回车；已添加项保留显示且不可选，选择后关闭菜单并保存。只有宿主确认后卡片才更新，失败不会假报已授权。目录显示名仅用于阅读，授权仍是精确 provider + model；目录中已不存在的授权仍显示原始标识，可手动删除。

修改 name 或删除文件前会提示当前宿主未发送会话中的显式选择引用。确认后允许执行，引用不会自动更新；冻结会话不阻止删除。文件变动会在打开界面、恢复焦点和轮询时刷新；保存检查文件版本，发现外部修改时拒绝覆盖。

## 代码职责

组件的 shared/state.ts 是唯一纯解析器；shared/markdown.ts 处理 Markdown，shared/protocol.ts 定义传输契约。host 下的 paths、prompt-catalog、config-store、session-location、session-store 分别处理路径、扫描、配置和会话存储；controller 协调并发与操作，request-guard 检查实际请求，model-selection 封装 rc.5 的公开选模方法适配，selection-error 生成组件内部可识别的校验错误，index 仅装配 DSH 公开钩子。

rc.5 没有选模前置事件，适配仅装饰公开 `sessionController.selectModel`，校验成功后保持原调用上下文委托，保留默认模型保存等原生行为；停用时还原。升级 DSH 必须复核方法、远程错误传递、运行中选模时序及生命周期。

选模拒绝通过 RemoteResult 返回，由当前选模入口呈现：原生模型菜单和本包选择器使用官方 Toast，原生 `/model` 保留菜单内错误提示；本组件不监听模型目录，也不另发一份选模拒绝通知。切换破甲词失败与请求护栏拒绝由本组件使用官方 Toast 呈现，结束时按通知 ID 确认；重复操作使用新通知 ID，旧 Toast 的退出回调不会清除新通知。Toast 不接管焦点，显示期间仍可输入、换模或重新选择。未开启破甲的会话不会因为模型不在白名单中而收到拒绝通知。

前端使用 Zustand 与 Immer 接收权威结果。会话接口只返回一份 `session.resolved`，包含最终状态、正文、来源、有效性和可编辑性；父会话标识使用 `session.inheritedFrom`。UI 不复制原始选择或冻结文件，不另做模型白名单或会话状态解析。设置接口只返回文件配置与目录，不构造虚拟会话状态。
